# 次元门 · Dimensional Portal（DSH 版）项目介绍

> 一句话：**你对着 DSH 说话，它伸手替你按住那台手机。**

---

## 1. 它解决什么问题

手机上的事，AI 一直插不上手。

别人问你「帮我看看微信里那条消息说的是什么」，你会截图、复制、粘贴；你想让它「把这个 App 打开、
搜个东西、点进去、截图给我看」——它做不到，因为它只能看见你给它的文字和你主动贴的图，
**它没有手，也看不见你的屏幕**。

次元门给 AI 接了一双手和一双眼睛：它能自己截图看你手机的界面、按坐标点、滑动、打字、
按返回键、打开应用、按文字找按钮，然后把结果（包括截图）拿回来继续判断。

**手机上不装第二个模型。** 唯一在思考的是 DSH 里的那个模型；手机只是一个执行器，
它不知道自己在干什么，只负责「截这张图」「点这个坐标」。

---

## 2. 为什么有「DSH 版」

它原本是给 QQ 机器人写的：QQ → 腾讯 → NapCat → AstrBot → 插件 → 手机。
能跑，但要养一整套东西：QQ 号、NapCat、AstrBot 进程、插件市场、配置面板……

DSH 版本把这整条链路砍掉了：

```
DSH 会话（正在跟你说话的这个 AI）
   │  MCP 工具调用（stdio，本机进程间）
   ▼
tools/dp_mcp.py            ← 11 个 phone_* 工具
   │  HTTP，只走 127.0.0.1 + 本机密钥
   ▼
tools/dp_daemon.py (:8766) ← 任务队列、限流、审计、控制台
   │  手机主动长轮询（12 秒一轮，有活立刻返回）
   ▼
你的安卓手机 · AutoX.js 脚本（无障碍服务执行）
```

没有 QQ，没有 NapCat，没有 AstrBot，没有插件市场。**只有一条从你的话到手机的直线。**

---

## 3. 三个关键取舍

### 手机「主动找电脑」，而不是电脑连手机

手机在 4G/5G 后面、在家里 WiFi 后面，经常没有公网地址，当不了服务器。
所以永远是手机先连电脑、挂着一条长轮询连接——像员工盯着对讲机，而不是老板挨个打电话。
好处是：**电脑不需要公网 IP、不需要端口映射、不需要内网穿透也能用**（出门时挂个 Tailscale 就行）。

### 用无障碍服务，不用 root

AutoX.js 走 Android 官方的无障碍接口：能读控件树、能点、能滑、能输入。
不刷机、不提权、不装 Xposed，装个 App 开个开关就能用。
代价也很清楚：微信、支付宝、银行这类 App 会**主动屏蔽**无障碍操作——这是它们的安全设计，
我们不去绕。

### 最小权限 + 全程留痕

- 敏感界面（微信/支付宝/银行/系统设置）默认**只读不写**，连截图都要单独开关
- 包名黑名单、每分钟操作上限、敏感界面拦截
- 每个动作都写一条 `data/audit.jsonl`，控制台上能翻
- 有个「急停」按钮，一句话清空所有还没下发的任务

## 4. 能做什么 / 不能做什么

**能**：看屏幕、读控件文字、点、长按、滑动、打字、按系统键、打开应用、按文字找按钮、截图存档。

**不能**（或者很难）：

| 情况 | 原因 |
| --- | --- |
| 锁屏状态下操作 | 需要密码/指纹，无障碍做不到 |
| 微信 / 支付宝 / 银行里的点击输入 | 这些 App 屏蔽无障碍 |
| 部分自绘输入框打字 | `setText` 不生效，会退回剪贴板粘贴 |
| 手机重启后自动恢复 | AutoX 脚本被系统杀掉要手动点「运行」 |
| 实时看相机画面 | M3 阶段才做，目前搁置 |

## 5. 和别的方案比

| 方案 | 谁在思考 | 要不要 root | 能不能自己判断 | 备注 |
| --- | --- | --- | --- | --- |
| **次元门（本项目）** | 电脑上的大模型 | 不要 | **能** | 一句话下达，AI 自己看界面自己点 |
| scrcpy / 远程桌面 | 人 | 不要 | 不能 | 画面清楚、延迟低，但还是你在操作 |
| AutoX.js 定时脚本 | 写死的人 | 不要 | 不能 | 只能按固定流程跑，界面一变就废 |
| ADB 命令 + 云控 | 人/半自动 | 开发者模式 | 有限 | 能做，但每步都要人写坐标 |
| 手机端本地模型 | 手机 | 一般要 | 能 | 手机上跑模型慢、耗电、能力弱 |

核心差别是那句「**AI 自己看、自己判断、自己动手**」，而不是把手机变成一块远程屏幕。

## 6. 名字

「次元门」出自哆啦A梦的道具：一扇门，推开就是另一个地方。
这里推开的另一头是你的手机屏幕——手从这里伸过去，够到那一头。
